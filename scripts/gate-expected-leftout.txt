# Lean-compiled (and may be verified per function) but lean-link --verified links cg_clif's code
# for them, so the binary check does not cover them. Read by scripts/gate-line-check.py.
#
# - EXECUTABLE is named as in gate-known-unverified.txt: `<package>/<file without -<hash>>`. A
#   package that links several executables with one name has the line repeated (compared as a
#   multiset).
# - Exact per executable: a rise is red (functions left the region), a drop is red until this
#   file records it in the same PR (the verdict prints the new lines). Every executable of a
#   pinned example needs its line; an example without lines is not checked.
# - No pin may rise above the base revision's (main's) pin for the same executable: lowering a
#   left-out count is free, raising one is a parent decision.
# - Not a baseline of "intended" exclusions: survey's g_u128 counts are a SrcScopeB `declSigB`
#   exclusion (#1052). deps' 18/13/10/13 (#1036's `declSigB` set, #1042) dropped to 0 with #1051
